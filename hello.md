# I am learning to use git and github.
---
###I used 'cd ""' to change directory, 'mkdir <filename.ext>' to make direcctory, 'git init' to initiate local git repository, 'git ni hello.md', 'git add .' to stage all changes and 'git commit - m "message"' to commit.

###Used: 'git status' to check status of files added to stage, 'code .' to open VSCode, 'git add -A' to stage every single thing.

###Learned: 'git pull' = 'git fetch' + 'git commit' , 'git clone' , 'git push origin main' (origin: name of remote Github Repo & main: Name of the branch in Github) 
###Used: 'git remote -v' to check if the name of remote repo is origin or not
